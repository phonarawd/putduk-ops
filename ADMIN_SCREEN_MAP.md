# Admin Screen Map

공식 운영 홈은 `https://ops.hiptk.app/admin` 이다. `/` 는 `/admin` 으로 보낸다.

| 주소 | 화면명 |
|---|---|
| `/admin/login` | 운영자 스태프 로그인 |
| `/admin` | 오늘 할 일 |
| `/admin/products`, `/admin/products/new`, `/admin/products/[id]` | 운영 상품 목록·등록·상세 |
| `/admin/users`, `/admin/users/[id]` | 회원 찾기·상세 |
| `/admin/support` | 문의함 |
| `/admin/conversations/ai`, `/admin/conversations/ai/[id]` | 퍼뜩 AI 대화 |
| `/admin/money/deposits`, `/admin/money/withdrawals`, `/admin/money/transactions`, `/admin/money/mismatches` | 돈과 거래 |
| `/admin/identity` | 본인 확인 |
| `/admin/content/notices`, `/admin/content/events`, `/admin/content/benefits`, `/admin/content/banners`, `/admin/content/messages` | 공지와 이벤트 |
| `/admin/safety/alerts`, `/admin/safety/cases`, `/admin/safety/lists`, `/admin/safety/limits` | 안전 관리 |
| `/admin/reports` | 운영 현황 |
| `/admin/staff`, `/admin/staff/approvals`, `/admin/activity`, `/admin/activity/access` | 직원과 기록 |
| `/admin/service`, `/admin/service/incidents`, `/admin/service/maintenance`, `/admin/service/controls` | 서비스 설정 |
