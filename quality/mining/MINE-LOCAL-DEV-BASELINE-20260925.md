# PUTDUK MINE 로컬 개발 기준선

이 브랜치는 `PUTDUK MINE OS` 통합 개발 기준선이다.

## 역할

- 이 저장소는 운영자용 퍼뜩 채굴 운영센터를 담당한다.
- 광산, 수익률, 운용, 정산, 시스템 제어를 운영자가 한 곳에서 관리한다.
- 기존 상품/기회/참여 중심 운영 화면은 최종 제품 기준에서 제거한다.
- 운영자 화면은 한국어 중심으로 만든다.
- 밝은 모드와 어두운 모드를 모두 별도 완성도 기준으로 설계한다.

## 로컬 API

로컬 개발에서는 Supabase Cloud 연결은 기존대로 유지한다. 다만 이 단계의 로컬 UI/코드 작업에서는 Production DB를 호출하거나 변경하지 않는다.

기본 API 원점:

`http://127.0.0.1:4000`

## 금지

- 브라우저에서 Supabase 직접 호출
- 리셀 상품 관리자 화면을 Mine OS 화면으로 이름만 변경
- 영어 상태명을 사용자에게 그대로 노출
- 서버 성공 전 성공 상태 표시
